# iUnlocker

iUnlocker - портативная утилита для диагностики, восстановления и обслуживания Windows. Работает в запущенной Windows и в WinPE с выбранной offline-системой.

## Возможности

- Автозагрузка: `Run`, `CmdLine`, `Winlogon`, папки Startup, планировщик, службы, драйверы и другие точки запуска.
- Проводник без зависимости от `explorer.exe`: поиск файлов, иконки типов, карантин и поиск процессов, блокирующих файл.
- Редактор реестра для текущей и offline-Windows: навигация по пути, поиск, создание разделов и параметров.
- Диспетчер задач: дерево процессов, подписи, путь и метаданные файлов, DLL/модули, потоки, остановка и приостановка процессов.
- Инструменты SAM/SYSTEM для просмотра и управления локальными пользователями.
- Скан подозрительных объектов, карантин и проверка цифровых подписей файлов.
- Разблокировка системных ограничений.
- Восстановление: SFC, DISM, CHKDSK, восстановление загрузчика, диагностика BCD/WinRE/EFI, LogonUI, шрифты, TEMP, UAC и политики безопасности.
- Отчёты в TXT и HTML.

## Запуск

Скачайте `iUnlocker.exe` из [Releases](https://github.com/MrGamer4814/iUnlocker/releases/latest) и запустите от имени администратора.

Текущая версия: [1.0.3](https://github.com/MrGamer4814/iUnlocker/releases/tag/v1.0.3).

В обычной Windows программа сразу открывает главное меню.

В WinPE сначала выберите диск с установленной Windows. iUnlocker будет работать с выбранной offline-системой, а не с временным диском `X:\`.

## Сборка

Требуется .NET 8 SDK.

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o publish
```

Готовый файл: `publish\iUnlocker.exe`.

## Важно

Некоторые функции изменяют реестр, автозагрузку, BCD и системные файлы. Перед применением действий проверяйте выбранный диск и путь. Для важных данных рекомендуется иметь резервную копию.
