# iUnlocker

iUnlocker - утилита для диагностики и восстановления Windows. Работает в обычной Windows и в WinPE.

## Что умеет

- Просмотр и редактирование автозагрузки.
- Встроенный проводник без зависимости от `explorer.exe`.
- Редактор реестра live/offline.
- Инструменты SAM/SYSTEM для пользователей Windows.
- Диспетчер задач с деревом процессов.
- Поиск и снятие системных ограничений.
- Скан подозрительных объектов и карантин.
- Дополнительные функции восстановления: SFC, DISM, CHKDSK, загрузчик, UAC, TEMP, подписи файлов.

## WinPE

В WinPE программа предлагает выбрать диск с установленной Windows. После выбора инструменты работают с этой offline-системой, а не с временным диском `X:\`.

В обычной Windows выбор диска не нужен: iUnlocker сразу открывает главное меню.

## Обновления

Автообновление работает через GitHub Releases.

Для нового обновления нужно создать релиз с тегом выше текущей версии, например:

`v1.0.1`

В assets релиза должен быть файл:

`iUnlocker.exe`

## Сборка

Требуется .NET 8 SDK.

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o publish
```

Готовый файл:

`publish\iUnlocker.exe`

## Важно

Некоторые функции изменяют реестр, автозагрузку, BCD и системные файлы. Запускайте программу от администратора и проверяйте выбранный диск перед применением действий.
