# iUnlocker

iUnlocker - WinForms-утилита для восстановления и диагностики Windows. Программа умеет работать как в обычной Windows, так и с выбранной offline-Windows из WinPE.

## Возможности

- Автозагрузка Windows: `Run`, `Winlogon`, `CmdLine`, `AppInit_DLLs`, службы, драйверы, задачи планировщика, IFEO Debugger и другие точки запуска.
- Внутренний проводник без зависимости от `explorer.exe`: дерево папок, список файлов, настоящие иконки `.exe`, контекстное меню, карантин, поиск по имени, размеру и дате.
- Редактор реестра live/offline: дерево ключей, значения, переход по пути, подсказки, поиск по реестру.
- SAM/SYSTEM: просмотр локальных пользователей, состояние учётной записи, админ-права и наличие пароля.
- Диспетчер задач: дерево процессов, PID, нагрузка, путь, описание, подпись, критичность, действия по ПКМ.
- Разблокировка ограничений: поиск и снятие блокировок Task Manager, Regedit, CMD, IFEO Debugger и других ограничений.
- Скан подозрительного и карантин.
- Дополнительные функции восстановления: SFC, DISM, CHKDSK, проверка загрузчика, восстановление LogonUI, очистка TEMP, включение UAC, отключение тестового режима, проверка подписей.
- Автообновление через GitHub Releases.

## WinPE

При запуске iUnlocker показывает выбор диска. В списке видно:

- какой диск является WinPE (`X:\`);
- где найдена установленная Windows;
- какой диск выбран для offline-операций.

Если выбран диск с установленной Windows, автозагрузка, реестр и часть восстановительных функций работают с этой offline-системой, а не с временной средой WinPE.

## Автообновление

Программа проверяет обновления через GitHub Releases:

`https://github.com/MrGamer4814/iUnlocker`

Для нового обновления нужно создать Release с тегом выше текущей версии, например:

`v1.0.1`

В assets релиза должен быть файл:

`iUnlocker.exe`

Если нужно поменять репозиторий обновлений без пересборки, рядом с программой можно положить файл `iUnlocker.update.json`:

```json
{
  "owner": "MrGamer4814",
  "repo": "iUnlocker",
  "assetName": "iUnlocker.exe"
}
```

## Сборка

Требуется .NET 8 SDK на Windows.

Запуск из исходников:

```powershell
dotnet run --project .\IUnlocker.csproj
```

Публикация автономного `win-x64` exe:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o publish
```

Готовый файл будет здесь:

`publish\iUnlocker.exe`

## Важно

iUnlocker изменяет системные настройки, реестр, автозагрузку и файлы Windows. Перед опасными действиями проверяйте выбранный диск и путь. Некоторые функции требуют запуска от администратора.
